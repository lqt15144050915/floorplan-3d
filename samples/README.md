## 窗框分格

格式 C 窗户支持可选 `frame` 对象，例如
`{"panelRatios":[1,4,4,1],"width":60,"depth":60,"color":"#202020"}`：
`panelRatios` 是沿窗长轴各块玻璃净宽的比例；`width` 是框料宽、`depth` 是框料进深（mm）。
单片玻璃使用 `[1]`。未声明 `frame` 时保持原自动分格；导入导出会保留显式窗框配置。
