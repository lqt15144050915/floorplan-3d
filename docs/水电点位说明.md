# 水电点位布置与真实预览

顶部切换“水电 · 点位”，2D 和 3D 使用同一份点位数据。点位随当前方案自动保存，原户型几何不变。

1. 左侧选择五孔插座、三孔插座、网络插座、单开/双开/三开开关。
2. 点击 2D 房间内侧墙边，或 3D 房间内侧实墙面。插座初始中心高度 300 mm、开关 1300 mm，均为可修改的编辑器初值。
3. 点击点位或左侧列表选中，在“点位属性”中编辑名称、类型、中心离地高度、中心距墙段起点、联排数量、横竖排、间距和颜色，点“应用修改”。
4. “精确布置”支持先选房间/墙段，再输入全部参数；输入的距离原样应用。墙段起点为平面左端或上端，按房间实际外露净墙面计算，排除交接墙厚。
5. 2D 拖动只改变沿墙位置，3D 拖动同时改变沿墙位置和高度。拖动按 10 mm 吸附；方向键上下调高度、左右调沿墙距离，Shift 改为 100 mm。
6. “3D 近看”从所属房间正对面板，“同墙预览”显示这一侧同墙全部点位的相对位置与高度。总览仍显示真实面板，水电页签附加点位编号。2D 编号对应左侧清单。

面板外形为 86 × 86 mm、厚度 8 mm，带孔位、网口或翘板细节；1–4 个同类型面板可横排或竖排。当前采用通用模型，不对应特定品牌。开关暂不关联灯具，当前阶段不生成回路和布线。

放置/修改会检查面板整组是否超出净墙段、地面、窗台或墙顶，并检查同侧共面重叠。普通窗台以下实墙可放置，玻璃和门洞不能挂载。超短墙段会提示放不下，不会把面板伸进交接墙。已有点位所在墙体拆除后保留记录并提示待调整，可“重新贴墙”或恢复墙体。

点位复制、删除、重新贴墙及拖动均支持撤销/重做。刷新、方案复制、历史版本恢复和完整 JSON 导入导出均包含点位；旧版方案没有点位时自动视为空数组。

## 数据与验证

`state.electrical` 保存 `{id,type,name,wallId,roomId,normal,along,height,count,layout,gap,color}`。`along` 为墙面长轴上的模型绝对坐标，`normal` 明确所属墙面；`height` 为完成地面至中心的距离。净墙段与三维位置由 `fp-electrical.js` 派生，不把截图坐标写进文件。

`fp-projects.js` 校验点位格式与编号，允许保留失效宿主引用，以便用户修复。`electrical-app.js` 管理交互，Three.js 真实面板与操作在 `index.html` 模块内。执行 `node --test tests/*.test.mjs`。

浏览器验证使用独立“点位预览演示”方案，原“当前装修方案”保留。演示位置仅用于查看交互，尚未作为全屋装修点位方案确认。
