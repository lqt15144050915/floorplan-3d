## 1. 优先复核外围墙分类

以门窗洞口封闭后的平面为基础，从外部连通区域检查墙体外侧，发现 **14 段接触外部的外围墙候选被标为 `kind: interior`**：

`w1、w7、w9、w10、w17、w21、w22、w23、w24、w25、w26、w27、w31、w33`。

其中下面 **7 段目前被程序的 `canDemolish()` 判为可拆**，因此墙体类别应优先复核。此处描述的是软件状态；外围判定来自当前二维模型推导。

| 编号 | 模型中的位置 | 当前属性 |
| --- | --- | --- |
| w17 | 入户门东侧短墙 | interior / non_bearing |
| w21 | 西南卧室西侧退台横墙 | interior / non_bearing |
| w22 | 西南卧室南窗西侧短墙 | interior / non_bearing |
| w24 | 入户门西侧横墙 | interior / non_bearing |
| w25 | 北侧开放区西墙上段 | interior / non_bearing |
| w27 | 玄关及走道西侧竖墙 | interior / non_bearing |
| w31 | 西南卧室西南退台竖墙 | interior / non_bearing |

承重属性与内外墙类别是两个不同字段；复核 `kind` 时不应根据外轮廓直接改变原有黑/灰墙对应的 `bearing`。

## 2. 房间多边形尚未整理

六个房间共 174 个顶点记录，其中有 **52 个相邻重复点，对应零长度边**。去除这些重复点后，还有 52 处共线中间点，其中客餐厅有 2 处共线反向折返。重复点与共线点是两类统计，不能混为同一组顶点。

当前应用可以处理这些轮廓，但它们不是整洁的简单多边形表示。严格的几何交换或后续布尔运算前，应清理重复点、零长度边和折返，再核对面积、可见轮廓及原始墙窗位置。

## 3. 需要明确的字段语义和兼容性

- `polygon` 目前表示地板覆盖范围，包含墙下延伸，不等于墙内净轮廓。直接计算其面积合计为 **111.621323 m²**；本项目通过 `roomInterior()` 扣除建筑占地后得到 **107.604227 m²**。其他工具若直接把 `polygon` 当房间净边界，面积会偏大。
- 卧室门口是否通铺由本项目的 `openingFloor()` 根据两侧材质、标高及房间属性派生。JSON 保留了 `tile800` 和标高，但没有独立的“取消过门石”字段；其他工具需要实现同样规则才能还原该效果。
- `floorplan.standard/1` 是本项目格式标识，不代表通用 CAD/BIM 交换格式。窗框 `frame`、派生净轮廓及通铺规则都需要接收端支持。
