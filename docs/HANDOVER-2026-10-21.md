## 5. 用户改图融合管线（本轮核心工作）

输入：`C:\Users\LQT15\Desktop\Group 48097711.svg`（用户改图，颜色语义：
灰=普通墙 黑=承重墙 蓝=玻璃 紫=玻璃滑轨门 橙=门）+

运行：`python tools/svg_pure_convert.py` → 输出 `tools/svg_pure_v2.json`（格式 C）并复制到桌面。

管线要点（脚本内均为显式参数，可调）：
1. SVG 全部矩形解析（含 rotate 90/180），标定 7.65mm/单位（外包盒对齐 PDF 总尺寸 13960×10563）。
2. 墙：按用户 SVG 一根不增不删；颜色→类型（黑=b 承重、灰=n 普通）；贴外包盒 ±30mm 判外墙。
3. 窗：蓝色矩形 → 窗；**L 型阳台窗**：西窗南延至外墙皮与南窗齐平衔接（共享角梃），
   角部方域按 SVG 原样为墙体 + **120×120 黑色角柱**居中于两窗带中线交点
   （西窗带中线 x=3125.5、南窗带中线 y=10200.5）。
4. **落地窗**：阳台两段 + 北侧两间卧室窗 = 窗台 200mm / 窗高 2200（用户核定，非贴地）；
