# 方案保存与备份

点击顶部“方案：名称 ▾”或“文件 → 方案管理”。

- **自动保存**：布置修改后保存当前方案，顶部显示保存状态。刷新会恢复最近使用的方案。
- **保存 / Ctrl+S**：立即保存并记录当前版本；相同内容不会重复创建版本。Ctrl+Shift+S 打开另存为。
- **新建方案**：沿用当前户型，创建空白家具布置。
- **另存为新方案**：复制当前户型与全部布置，各方案独立编辑。
- **重命名、打开方案**：切换前先保存当前内容；切换后清空当前会话撤销栈，避免跨方案撤销。
- **历史版本**：手动保存及切换时保留检查点，最多10个。恢复前先记录当前内容。
- **回收站**：移出的方案可以恢复，至少保留一个使用中的方案。

“文件 → 导出完整方案 JSON”或管理窗口里的“导出当前完整方案”会一起导出户型、家具家电布置、水电点位、房间名称、地面材质、拆墙、测量和历史版本。使用“导入方案”可在其他浏览器还原；导入会创建独立新方案，同名自动编号，不覆盖已有方案。

旧版仅含布置的 JSON 也可导入，预览会说明它将配合当前户型保存。旧的浏览器存档首次打开时自动迁移，原存档键保留作备份。

当前存储属于浏览器本地，同一浏览器、同一网址下恢复；跨浏览器或设备使用完整 JSON 文件迁移。存储失败时顶部明确显示“未保存”，并阻止切换带走未保存内容；仍可导出当前方案。检测到其他窗口改写方案库时，也会阻止旧窗口覆盖数据。

## 开发信息

- 数据模块：`fp-projects.js`，无 DOM 依赖。
- 本地库：`huxing-project-library-v1`，格式 `floorplan.library/1`。
- 单方案文件：`floorplan.project/1`，包含 `exportedAt` 和 `project`；项目记录含名称、时间、原模型、完整 `state`、最近10个 `versions`。
- 通过标准适配器校验模型，实际保存原模型坐标；`state` 与房间扩展字段原样保留，以供后续装修功能使用。
- 旧 `huxing-design-v1` / `huxing-design-v2` 只读迁移，不再作为新库的写入目标。
- 本地写入先序列化候选库，写成功才更新内存索引；配额错误、损坏存档或未知库版本不静默覆盖原数据。

验证命令：`node --test tests/*.test.mjs`。共68项测试，包含50项几何测试、11项保存测试和7项点位测试。

浏览器已验证迁移、新建空白、另存、名称修改与刷新恢复、版本恢复、含家具的完整导入导出、旧文件识别、3D切换及回收站恢复。验证副本留在回收站，原方案保持激活；备份及界面截图见 `review-2026-10-28/`。
